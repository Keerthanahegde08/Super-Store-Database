# Superstore Sales Analysis

## Executive Summary

This project analyzes the Superstore dataset — a retail sales dataset covering orders, products, customers, and regions — using Excel for initial data checks, Python for data cleaning and exploratory analysis, and Power BI for building an interactive dashboard. The workflow moves from raw data cleaning and analysis in Python (pandas, NumPy) to a polished, business-facing dashboard in Power BI with DAX measures. The project demonstrates practical data analyst skills including data wrangling, exploratory data analysis, data modeling, and dashboard design.

## Business Problem

Retail businesses generate large volumes of transactional data, but without proper analysis this data rarely translates into actionable insight. Superstore, like many retail businesses, needs to understand:

- Which products, categories, and sub-categories are most and least profitable
- Which regions and states are driving sales versus underperforming
- Whether certain customer segments or shipping modes are eating into margins
- How sales and profit trend over time, and whether discounting is hurting profitability

Without this visibility, the business risks making inventory, pricing, and marketing decisions based on guesswork rather than data — leading to overstocked low-performing products, missed regional opportunities, and discounting strategies that erode margin instead of driving profitable growth.

This project uses Python and Power BI to answer questions such as:
- What are total sales and profit trends over time?
- Which categories/sub-categories generate high sales but low (or negative) profit?
- Which regions, states, or customer segments are most profitable?
- Is there a relationship between discount level and profit margin?

The insights help retail managers make informed decisions on inventory, regional strategy, and discount policy to improve overall profitability.

## Tools Used
